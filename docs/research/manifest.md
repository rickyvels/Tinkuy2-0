# Corpus curado para Graphify

Este manifiesto separa el conocimiento del proyecto del grafo operativo de casos.

## Fuentes de producto

Los documentos originales del desafío no se versionan en este repositorio. Para volver a generar el corpus, coloque copias autorizadas dentro de `docs/research/sources/product/` y mantenga fuera del repositorio los datos sensibles.

## Fuentes técnicas seleccionadas

El grafo incluido en `eigent-graphify/` fue generado a partir de patrones de Eigent/Multi-Agent-Orchestrator, Semantica y Voicebox. Sus repositorios no son una dependencia de ejecución del MVP. Si se repite el análisis, clone las revisiones autorizadas en `docs/research/sources/technical/` o use enlaces externos fijados a una revisión.

## Uso

Ejecutar Graphify únicamente sobre este corpus curado o sobre una carpeta preparada con sus copias o enlaces. No incluir eventos ni datos de casos en el corpus documental. Cuando se añadan entregables relevantes, actualizar el manifiesto y usar una actualización incremental del grafo.
