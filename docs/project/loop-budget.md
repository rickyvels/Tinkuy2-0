# Presupuesto del loop

- Alcance por run: un flujo demostrable o un grupo pequeño de defectos relacionados.
- Dependencias nuevas: cero por defecto; justificar cualquier excepción.
- Reintentos máximos por causa: tres.
- Tiempo de animación del caso: breve y controlable; nunca continuo.
- Kill switch: detener si se rompe el gate humano, la separación de aplicaciones o la suite de pruebas.
