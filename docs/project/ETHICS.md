# Límites y seguridad del MVP

- Todos los casos y eventos son sintéticos.
- El sistema coordina acciones administrativas y de continuidad, no brinda diagnóstico, prescripción ni recomendaciones terapéuticas.
- La creación de una tarea de coordinación queda bloqueada hasta que un profesional apruebe la propuesta.
- El proveedor de IA, si se habilita en el futuro, solo puede devolver propuestas validadas. No recibe control del orquestador, herramientas libres ni permisos para cambiar estados.
- La vista familiar no expone logs técnicos ni razonamiento interno.
- Los indicadores de calidad son agregados y no identifican a personas.
- Antes de usar información real se debe definir autorización institucional, minimización de datos, control de accesos, auditoría y la evaluación correspondiente.
